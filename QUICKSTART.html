CenGeometry

Modelling how centriole architecture responds to structural perturbation — a guide that assumes no programming experience.

What this does. You change something about the centriole — the number of cartwheel spokes, the length of the SAS-6 coiled coil, whether the microtubules are triplets or doublets — and the model works out whether the ring can still hold together, what has to bend to make it fit, and what would break first.

1Install Python

Check whether you already have it. Open a terminal (Mac: Terminal  ·  Windows: PowerShell) and type:

python3 --version

If you see a number of 3.9 or higher, skip ahead. Otherwise download the installer from python.org/downloads and run it.

Windows note: during installation, tick “Add Python to PATH” on the first screen. Use python instead of python3 in every command below.

2Download and set up CenGeometry

Run these four commands one at a time. The first moves into your Downloads folder — change the path if you put the project elsewhere.

cd ~/Downloads/CenGeometry
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

Windows: replace the third line with .venv\Scripts\activate

What just happened. You made a private, self-contained workspace (.venv) and installed the four scientific packages the model needs. Nothing else on your computer was changed.

Every new session, run source .venv/bin/activate again before using the model. You will see (.venv) at the start of your prompt when it is active.

3Run it

python run_analysis.py

That produces the standard report: the wild-type centriole, a comparison of symmetry mutants, and two sweeps. It takes about a minute. Everything is written to a new results folder — open the PNG files to see the figures, and the CSV files in Excel.

Testing a specific perturbation

QuestionCommand
What if SAS-6 makes an 8-fold cartwheel but there are still 9 triplets? python run_analysis.py --cartwheel 8
What if the whole centriole is 8-fold? python run_analysis.py --cartwheel 8 --triplets 8
What if the C-tubule is missing (doublets)? python run_analysis.py --tubules 2
What if the SAS-6 coiled coil is 10 nm longer? python run_analysis.py --spoke-length 55
What if the triplet base is shorter? python run_analysis.py --base-length 28
How does coiled-coil length matter across a range? python run_analysis.py --sweep spoke_rod --from 35 --to 60
Show me every option python run_analysis.py --help

All lengths are in nanometres. You can combine options, for example --cartwheel 8 --spoke-length 50.

4Read the results

Joint rotation — can the parts still fit?

Each connection can pivot. The model reports how far each had to turn away from its wild-type angle:

GradeRotationInterpretation
OKunder 15° Comfortably accommodated
HARD15–35° Strained but achievable — expect distortion
FORBIDDENover 35° Very costly; unlikely to form this way

Bond load — what breaks first?

Connections are ranked by the strain they carry. The one at the top of the list is the most likely failure point, which is the model's most directly testable prediction.

The rest

LineMeans
centriole diam Resulting diameter in nm. Real centrioles are about 250 nm.
unattached triplets Triplets the cartwheel could not reach — expected when the two symmetries differ.
buckling Segments forced to bow because space got tight. Nothing is ever stretched.
MT-MT clashes Microtubules overlapping in space. Anything above zero is physically impossible.
strand clearance How close the linker, base and spoke pass to a microtubule. Negative means passing through one.

Worked example: an 8-fold cartwheel with 9 triplets

Running python run_analysis.py --cartwheel 8 reports a diameter of 255 nm — unchanged from wild type — with the triplets barely strained (OK) but the spokes at HARD, one triplet left unattached, and the triplet-base-to-A-C-linker bond carrying the highest load.

Reading: the microtubule ring keeps its normal architecture and the cartwheel absorbs the entire mismatch. The prediction is that such a mutant would look near-normal in cross-section, with the defect concentrated at the cartwheel and the base–linker junction the first thing to fail.

5If something goes wrong

MessageFix
command not found: python3 Python is not installed, or not on your PATH — redo step 1. On Windows use python.
No module named 'numpy' The workspace is not active. Run source .venv/bin/activate, then retry.
No such file or directory You are in the wrong folder. Use cd to move into the CenGeometry folder.
Nothing appears in results Look for a red error in the terminal output and check the two rows above.
